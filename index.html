HTML Template Auto Editor

Load your HTML template, replace names/text, optionally replace the first embedded image, then generate a new HTML file.
Your original design/code stays unchanged except for the replacements you choose.
Replaces every exact occurrence of the old name in the HTML.
Example: “Dear Megh Apu,” → “Dear Farhan,”. Replacements are exact and case-sensitive.
If the template contains a base64/data image, it will be replaced with the selected image. If not, the first <img src="..."> is replaced.
